# ai-news

매일 AI 뉴스를 훑어서, **일반 이용자가 "뭔가 달라졌네" 할 변화**만 골라내는 조사 서비스.

챗GPT · 제미나이 · 클로드 · 퍼플렉시티 · 그록을 축으로 폭넓게 훑고,
최근 24시간(걸린 게 없으면 72시간까지) 안에서 기준을 통과한 것만 브리핑으로 남긴다.

## 기준은 하나

> 일반 이용자가 "뭔가 달라졌네" 할 변화인가.

판정은 두 질문으로 한다.

1. 그 사람이 내일 앱을 열었을 때 **화면·결과·요금·한도** 중 하나가 실제로 달라지는가
2. 그 차이를 **전문용어 없이 한 문장**으로 설명할 수 있는가

둘 다 예면 싣는다. 그래서 벤치마크 점수, 논문, 투자 유치, 로드맵 예고, API 전용 변경은
아무리 크게 보도돼도 여기 안 들어온다. 반대로 조용히 바뀐 버튼 위치나 하루 사용 한도는 들어온다.

경계 사례는 [`references/filter.md`](.claude/skills/ai-news-daily/references/filter.md)에 표로 정리해뒀다.

## 쓰는 법

이 레포를 연 상태에서 이렇게 말하면 된다.

```
3번
AI 뉴스
오늘 AI 뭐 나왔어?
```

`ai-news-daily` 스킬이 잡히고, 조사 → 선별 → 브리핑까지 나온다.

결과는 이런 모양이다.

```
🗓 M월 D일 AI 브리핑 (최근 24시간 기준)

🔴 [서비스] 한 줄 제목 — 기능명이 아니라 결과로
   달라진 것 — 이전에는 ~, 지금은 ~
   누가 겪나 — 요금제 / 지역 / 플랫폼 / 롤아웃 범위
   📎 출처

🟡 [서비스] ...

📌 확인 필요
🗑 걸렀음
✍️ 오늘의 한 건
```

🔴은 앱을 열면 바로 보이는 변화, 🟡은 일부 이용자·조건부·단계적 롤아웃.
`🗑 걸렀음`은 무엇을 왜 뺐는지 남기는 자리다. 기준이 살아 있는지 여기서 확인한다.

## 아티클로 넘기기

이 스킬은 **조사와 선별까지만** 한다. 아티클은 쓰지 않는다.

`✍️ 오늘의 한 건`에서 하나를 고르면 거기서부터 기존 `ai-release-article` 스킬이 이어받아
여섯 꼭지(핵심만 말하면 · 왜 중요한가 · 달라지는 것들 · 사람들의 반응 · 맥락을 짚어보면 · 연결된 소식) 초안을 쓴다.

```
데일리 AI 뉴스 (3번)  →  후보 선택  →  ai-release-article  →  발행용 초안
```

## 매일 돌리기

claude.ai/code의 **Routine**으로 걸어두면 매일 자동으로 돈다.
크론은 UTC 기준이라 한국시간에서 9시간을 뺀다.

| 한국시간 | 크론 (UTC) |
|---|---|
| 매일 08:00 | `0 23 * * *` |
| 매일 09:00 | `0 0 * * *` |
| 매일 21:00 | `0 12 * * *` |

프롬프트는 [`routine-prompt.md`](routine-prompt.md)를 그대로 넣으면 된다.

## 기록

브리핑은 `archive/YYYY-MM-DD.md`로 쌓인다. 두 가지 용도다.

- **중복 제거** — 조사 시작 전 최근 3일치를 읽고, 이미 다룬 항목은 다시 싣지 않는다.
  단 상태가 바뀌었으면(테스트 → 전체 공개, 유료 → 무료, 롤백) 새 항목으로 친다
- **맥락** — 나중에 "연결된 소식"이나 흐름을 짚을 때 쓸 재료
