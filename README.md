# ai-news

매일 AI 뉴스를 훑어서, **일반 이용자가 "뭔가 달라졌네" 할 변화**만 골라 데스크에 쌓는다.

챗GPT · 제미나이 · 클로드 · 퍼플렉시티 · 그록을 축으로 폭넓게 훑고,
최근 24시간(걸린 게 없으면 72시간까지) 안에서 기준을 통과한 것만 남긴다.

```
매일 아침 8시 조사  →  데스크에 초안으로 도착  →  승인 · 보류 · 버림  →  승인한 것만 아티클로
```

## 데스크

**https://claude.ai/code/artifact/e1825bf6-9eee-49dc-b2f1-46a878c4aded**

혼자 보는 화면이다. 아무것도 자동으로 공개되지 않는다.

- 왼쪽에 날짜 기록, 본문에 그날 항목
- 항목마다 **승인 · 보류 · 버림**을 찍고, 하나를 **오늘의 한 건**으로 지정
- **발행 대기** 탭에 승인한 것이 날짜를 넘어 모인다 — 글감 목록
- **걸렀음**은 접힌 채로 남는다. 뭘 왜 뺐는지 보여야 기준이 헐거워진 걸 알아챈다

화면 소스는 `site/desk.html`, 데이터 구조는 `site/schema.md`.

## 기준은 하나

> 일반 이용자가 "뭔가 달라졌네" 할 변화인가.

두 질문으로 판정한다.

1. 그 사람이 내일 앱을 열었을 때 **화면·결과·요금·한도** 중 하나가 실제로 달라지는가
2. 그 차이를 **전문용어 없이 한 문장**으로 설명할 수 있는가

둘 다 예면 싣는다. 그래서 벤치마크 점수, 논문, 투자 유치, 로드맵 예고, API 전용 변경은
아무리 크게 보도돼도 여기 안 들어온다. 반대로 조용히 바뀐 버튼 위치나 하루 사용 한도는 들어온다.

경계 사례는 [`references/filter.md`](.claude/skills/ai-news-daily/references/filter.md)에 표로 정리해뒀다.

## 매일 돌리기

claude.ai/code Routine으로 **매일 아침 8시(KST)** 실행된다. 끝나면 휴대폰 푸시가 온다.

- 이름: `데일리 AI 뉴스 브리핑 (매일 아침 8시 KST)`
- 크론: `0 23 * * *` (UTC 기준. 한국시간에서 9시간을 뺀다)
- 매번 새 세션에서 뜨므로, 프롬프트에 기준을 그대로 담아 레포 없이도 브리핑이 나오게 해뒀다

시각을 바꾸거나 끄려면 claude.ai의 Routines에서 수정한다. 프롬프트 원본은 [`routine-prompt.md`](routine-prompt.md).

| 한국시간 | 크론 (UTC) |
|---|---|
| 매일 08:00 | `0 23 * * *` |
| 매일 09:00 | `0 0 * * *` |
| 매일 21:00 | `0 12 * * *` |

### 수동으로 돌리기

| 방법 | 결과 |
|---|---|
| claude.ai → Routines → **Run now** | 아침과 동일한 경로. 데스크까지 확실히 들어간다 |
| claude.ai/code에서 이 레포를 열고 `AI 뉴스` | 대화하면서 기준을 조정할 수 있다 |
| 일반 claude.ai 대화창 | **안 된다.** 스킬도 데스크에 쓰는 도구도 거기엔 없다 |

같은 날 다시 돌려도 안전하다. 기존 항목에 새로 찾은 것만 더하고, 새 게 없으면 갱신 시각만 바꾼다.
찍어둔 승인 상태는 어느 경우에도 건드리지 않는다.

## 아티클로 넘기기

조사는 **선별까지만** 한다. 아티클은 쓰지 않는다.

데스크에서 승인하고 `오늘의 한 건`을 고르면, 거기서부터 기존 `ai-release-article` 스킬이 이어받아
여섯 꼭지(핵심만 말하면 · 왜 중요한가 · 달라지는 것들 · 사람들의 반응 · 맥락을 짚어보면 · 연결된 소식)
초안을 쓴다.

## 알려진 제약

조사 환경의 네트워크 정책이 **1차 소스 도메인을 막는다.** `help.openai.com`, `openai.com`,
`gemini.google`, `9to5google.com` 등이 egress 차단에 걸려 릴리스 노트 원문을 열지 못한다.
검색은 되므로 사실 자체는 잡히지만, 근거가 2차 보도에 머문다.

그래서 브리핑은 1차 확인이 안 된 항목을 `📌 확인 필요`에 반드시 남긴다.
**발행 전에는 공식 페이지를 직접 열어 확인해야 한다.**
